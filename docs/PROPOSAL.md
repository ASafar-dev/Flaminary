# Flaminary proposal

## Purpose and users

Flaminary is a drum-practice app for students and players who need a specific exercise for a practice session. It provides a daily groove or fill with restrictions on kit pieces, tempo, time signature, and duration.

## Features

- View a daily exercise and its details.
- Search and filter a list of challenges.
- Add and edit exercises with validation.
- Delete an exercise after confirmation.
- Mark exercises complete or unfinished and view progress.
- Use a mock login and save data locally with AsyncStorage.

## Screens

Welcome, Sign in, Today, Challenges, My progress, Challenge details, and Add/Edit challenge. Today, Challenges, and Progress form the three tabs. Cards open details; details lead to editing and deletion. Add opens the shared editor. Logout returns to the entry screens.

## Scope and delivery

This version uses Expo SDK 58, local mock data, Zod, and AsyncStorage. It has no backend, real account system, audio recording, metronome, or automatic grading.
