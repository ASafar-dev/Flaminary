Challenges -- Add --> Add challenge /editor
Add -- Save challenge --> its details
Invalid Save --> field errors; retain entered values
Editor -- Cancel / Back --> previous screen without saving
Details -- Back --> previous tab
Details -- Delete challenge --> confirmation
Confirmation -- Cancel --> keep item
Confirmation -- Delete --> remove item and completion record
My progress -- Log out --> entry screens; protect main routes

Empty list --> Add a challenge
No matches --> Clear search and filters
Missing detail ID --> Open challenges
Storage loading --> loading indicator
Failed read --> retry screen; preserve saved data
Failed save --> error; keep last saved list

A reload requires the mock login again. Challenge and completion data remain
in AsyncStorage. Expo account sign-in is separate from the app's mock login.
