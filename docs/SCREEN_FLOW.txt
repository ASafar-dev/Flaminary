Explore -- Create --> Challenge Editor (7) /editor
New challenge -- valid Save --> its Challenge Details
Editor -- invalid Save --> field errors; keep the form's values
Editor -- Cancel / Back --> originating screen without saving
Details -- Back --> originating Today, Explore, or Progress screen
Details -- Delete --> confirmation --> originating screen
                       Cancel --> stay on Details
Progress -- Log out --> entry flow; signed-in routes become inaccessible

Empty collection --> Create a challenge
No search/filter results --> Clear search and filters
Missing/deleted detail ID --> Explore challenges
Initial storage read --> actual loading feedback
Failed storage load --> visible error and Try loading again
Failed save --> visible error; keep the last saved library

Mock session is in memory. A cold restart returns to entry/login while local
challenge data and completion records remain in AsyncStorage.
